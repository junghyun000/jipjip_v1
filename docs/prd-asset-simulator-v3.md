# PRD v3 — 빠른 시나리오 프리셋 (Quick Presets)

| 항목 | 내용 |
|---|---|
| 문서명 | JIPJIP 시뮬레이터 프리셋 시나리오 PRD |
| 버전 | v3.0 |
| 작성일 | 2026-06-03 |
| 상태 | Draft |
| 배경 | v2 UX 개선 후에도 "수십 개 변수를 하나씩 조정하기 어렵다"는 피드백 |
| 범위 | Hero 상단에 6개 프리셋 칩 추가. 클릭 시 입력값 일괄 적용 |
| 비범위 | 기존 6 카드·상세 설정·라이프 이벤트 기능은 그대로 유지 |

---

## 1. 문제 정의

### 1.1 v2 사용 회고
v2로 UI는 깔끔해졌지만 사용자는 여전히 "다양한 미래 시나리오를 비교해 보고 싶다"는 욕구가 있다:
- 시장 가정 단일 토글(보수/중립/공격)은 5개 가정만 동시 변경
- 라이프 이벤트, 부동산, 자녀, 건강 등 **상황 시나리오**는 여전히 개별 조정 필요
- 처음 사용자는 "어떤 조합이 의미 있는지" 모름 → 결정 피로

### 1.2 핵심 인사이트
사용자는 "긍정안 / 부정안 / 자녀 있을 때 / 부모 건강할 때 / 부동산 보유 시" 같은 **상황 단위 비교**를 원한다. 단, 100% 극단(인플레 0% / 투자 12%)이 아니라 **합리적으로 일어날 수 있는 현실적 케이스** 기준이어야 한다.

### 1.3 차별점 (시장 가정 토글과의 차이)

| 항목 | 시장 가정 토글 (v2) | 프리셋 (v3) |
|---|---|---|
| 변경 범위 | 5개 가정값 | 거의 모든 입력 (소득·저축·자산·부동산·이벤트 등) |
| 의미 | 시장 환경 가설 | **시나리오 전체** (가족 구성, 인생 사건 포함) |
| 사용 빈도 | 미세 조정용 | **빠른 비교용** (처음 진입 시) |

## 2. 목표

| 구분 | 내용 |
|---|---|
| 1차 | 첫 진입 후 **단일 클릭**으로 6개 시나리오 결과 비교 |
| 2차 | 각 프리셋의 가정값을 **현실적 범위** (역사 평균 ±1σ 내)로 설계 |
| 3차 | 사용자가 프리셋 적용 후 일부만 수정해도 **부드럽게 "커스텀" 라벨**로 전환 |
| 4차 | 기존 기능 100% 회귀 없음 |

---

## 3. 디자인 원칙

1. **현실 기준** — 100% 낙관/비관 X. 역사 데이터·통계청 자료 근거 ±1σ 내.
2. **상황 단위** — "시장 X% 좋아짐"이 아닌 "자녀 있는 가정" 같은 인생 시나리오.
3. **즉시 비교** — 클릭 → 100ms 내 Hero 갱신.
4. **수정 가능** — 적용 후 사용자가 일부만 미세 조정 가능. 프리셋은 출발점일 뿐.
5. **명확한 식별** — 활성 프리셋은 강조 표시, 수정 시 "커스텀"으로 자동 전환.

## 4. 프리셋 정의 (6개)

### 4.1 공통 베이스
모든 프리셋은 다음 항목을 **고정**으로 둔다 (사용자 본인 정보):
- 와이프 28세 / 남편 33세 / 입주 75세 (`wifeAge`, `husbandAge`, `entryAge`)
- 와이프 5800만 / 남편 5600만 (`wifeIncome`, `husbandIncome`) ← 시나리오별로 ±조정
- 실수령 환산 83% (`netFactor`)
- 등급 중급 (`tierId`)
- 거주 기간 10년 (`stayYears`)

이 외의 모든 변수가 시나리오별 조정 대상.

### 4.2 프리셋 사양

#### 🌟 낙관 (Optimistic)
**가정**: 시장 환경 우호적, 본인 커리어·건강·시장 모두 평균 이상

| investReturn | 7.0% | S&P500 30년 평균 8%에서 보수적 하향 |
| cashReturn | 3.0% | 정기예금 기준금리 상회 |
| reReturn | 3.5% | 서울 아파트 30년 평균 명목 ~3.5% |
| incomeGrowth | 5.0% | 적극적 커리어 (피크 55) |
| savingsRate | 38% | 가구 가처분 대비 적극 저축 |
| 부동산 | 매입 4년 후 6.5억 | 빠른 매입 |
| 라이프 이벤트 | 시장충격 4회 −20%, 본인 질병 15%·3000만, 배우자 질병 20%·3000만, 부모 간병 45%·5000만 | 평균보다 양호한 케이스 |

### 4.3 프리셋 데이터 구조 (JS)

```js
const PRESETS = [
  {
    id: 'optimistic',
    label: '낙관',
    emoji: '🌟',
    description: '시장 환경 우호적 + 본인 커리어·건강 평균 이상',
    delta: { /* 베이스 대비 변경 필드 */ },
    events: [ /* 8개 이벤트 (필요 시 덮어쓰기) */ ],
  },
  { id: 'neutral', ... },
  { id: 'pessimistic', ... },
  { id: 'family', label: '자녀 출생', ... },
  { id: 'healthy', label: '모두 건강', ... },
  { id: 'realestate', label: '부동산 보유', ... },
];
```

`delta` 방식 vs `full` 방식:
- **선택**: `full` 방식 (각 프리셋이 모든 변수를 명시) — 명확성, 추론 불필요
- 단, 사용자 본인 정보(나이, 연봉, 등급)는 `delta`에서 제외 (베이스 유지)

## 5. 기능 명세

### 5.1 UI 위치
- **Hero 카드 바로 위**에 가로 프리셋 칩 row
- 모바일에서는 가로 스크롤(`overflow-x: auto`)

### 5.2 칩 컴포넌트
```html
<section class="v3-preset-row">
  <h3>📋 빠른 시나리오</h3>
  <div class="v3-preset-chips">
    <button data-preset="optimistic" class="v3-chip">
      <span class="v3-chip-emoji">🌟</span>
      <span class="v3-chip-label">낙관</span>
    </button>
    ...
  </div>
</section>
```

- 칩 width: 90~120px
- 활성 상태: 채워진 배경 (accent-soft + 굵은 테두리)
- 비활성: 흰 배경 + 옅은 테두리
- hover: 살짝 들어 올림

### 5.3 동작
1. **칩 클릭** → `applyPreset(id)`
   - 베이스 값 + 프리셋 `full` 값 병합
   - `events` 배열 교체
   - `persistState()` → `buildUI()` → `refresh()`
   - 토스트 "🌟 낙관 시나리오 적용"
2. **활성 프리셋 추론** (`inferActivePreset(state)`)
   - 모든 변수가 특정 프리셋과 일치하면 그 ID 반환
   - 하나라도 다르면 `null` (활성 없음, "커스텀")
3. **사용자 수정** → 활성 칩 자동 해제 (재계산 시 추론 결과 적용)

### 5.4 활성 표시
- 활성 칩: `is-active` 클래스, 작은 ✓ 마크
- 비활성 + 커스텀 상태: 모두 비활성 (혼동 방지)

### 5.5 모바일
- 칩 row: `overflow-x: auto`, snap-scroll
- 칩 크기 유지 (가독성)

### 5.6 기존 기능 유지
- v2의 시장 가정 토글: **유지** (프리셋과 별개로 미세 조정 가능)
- 6 카드, 상세 설정, 라이프 이벤트 모달: **유지**
- 시나리오 저장/로드: **유지** (프리셋과 저장 시나리오는 별개)
- localStorage v2 키: **유지** (v3는 변경 안 함)

## 9. 에러 케이스 & 검증

| 케이스 | 처리 |
|---|---|
| 프리셋 ID가 PRESETS에 없음 | 무시, 토스트 "프리셋을 찾을 수 없습니다" |
| 프리셋 적용 직후 사용자가 1개 값 수정 | 활성 칩 자동 해제 (커스텀 상태) |
| 자녀 프리셋 적용 시 기존 events 백업 안 됨 | 의도된 동작 (프리셋은 완전 교체). 시나리오 저장으로 백업 권장 |
| localStorage에 프리셋 ID 캐시 안 함 | OK — 매번 inferActivePreset으로 추론 |
| 시나리오 로드 시 어떤 프리셋과도 일치 안 함 | "커스텀" 표시 |

- 가정값은 한국 평균 기준. 글로벌·해외 거주는 미반영
